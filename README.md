# Derui Zhu - Academic Homepage

This GitHub Pages site is published at **https://rit-trustse.github.io/**.

Source: migrated from the existing `deruizhu` static-site repository. The site retains its original academic profile, assets, publications, styling and client-side JavaScript.

## Deployment

GitHub Pages: **Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` -> `/(root)`**.

## Files

- `index.html`: page and metadata
- `assets/styles.css`: layout and style
- `assets/main.js`: interactions and filtering
- `assets/derui-zhu.jpg`: profile image
- `assets/publications.bib`: publication BibTeX entries
- `robots.txt`, `sitemap.xml`: search indexing
- `.nojekyll`: static hosting marker
